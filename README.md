# Chrome Proxy Edition — AnyTLS

Браузер на Chromium (Electron) для **Windows x64, Mac Intel и Mac Apple Silicon** со встроенным **AnyTLS на базе sing-box 1.14.4**. Версия **0.2.0** заменяет Mieru на AnyTLS. Приложение самостоятельно запускает локальный клиент; отдельный VPN-клиент и права администратора не нужны. Подключение действует только в этом браузере.

## Скачать

[Публичные установщики в Releases](https://github.com/Arthuralend/Chrome-Proxy-Edition/releases/tag/v0.2.0). Вход в GitHub для скачивания релизов не нужен.

- `Chrome-Proxy-Edition-0.2.0-win-x64.exe` — Windows.
- `Chrome-Proxy-Edition-0.2.0-mac-arm64.dmg` — Mac Apple Silicon.
- `Chrome-Proxy-Edition-0.2.0-mac-x64.dmg` — Mac Intel.

Mac-приложение и встроенный sing-box имеют ad-hoc подпись. В CI проверяются подпись и запуск упакованного приложения на соответствующих Mac. Сертификата Developer ID и нотариального заверения Apple пока нет: при предупреждении о неизвестном разработчике используйте «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть». Не отключайте Gatekeeper целиком. Windows-сборка также не имеет коммерческой цифровой подписи.

## Настроить

В настройках укажите **сервер, порт, пароль и SNI** (домен из сертификата, если подключение идёт по IP). Проверка TLS-сертификата включена по умолчанию. Самоподписанный сертификат можно явно добавить через поле `certificate` в JSON; отключение проверки допускается только отдельной осознанной настройкой.

Вместо формы можно вставить ссылку:

```text
anytls://URL_ENCODED_PASSWORD@vpn.example.com:443/?sni=vpn.example.com&insecure=0#Name
```

Пароль с символами `@`, `:`, `/`, `%` и т.п. должен быть URL-encoded. Поддерживаются параметры `sni`, `peer`, `insecure`, `allowInsecure`; неизвестные параметры отклоняются. Это не универсальный импорт всех форматов ссылок сторонних клиентов.

Или простой JSON:

```json
{
  "server": "vpn.example.com",
  "server_port": 443,
  "password": "YOUR_PASSWORD",
  "server_name": "vpn.example.com",
  "insecure": false
}
```

Также принимается один outbound AnyTLS из sing-box с полями `server`, `server_port`, `password`, `tls`. Полные конфигурации маршрутизации sing-box не импортируются: браузер сам создаёт только SOCKS-listener на `127.0.0.1` и единственный AnyTLS outbound. Импортированные listeners, маршруты, API и пути к файлам не используются. JSON Mieru не подходит для AnyTLS.

Нажмите **«Сохранить и подключиться»**. Настройки сохраняются через safeStorage (Keychain на Mac / DPAPI на Windows), автоподключение включено по умолчанию. Сохранённый пароль не показывается в форме; для изменения введите настройки заново.

## Быстрое подключение кодом

Профиль передаётся отдельным файлом `*.anytls-profile.json`, зашифрованным AES-256-GCM. Реальные профили не хранятся в публичном репозитории и не включены в публичные установщики. Введённый код служит ключом через scrypt: сам код и исходная ссылка в репозиторий не записываются. Один раз откройте настройки и нажмите «Импортировать файл быстрого подключения», выберите свой файл профиля. Затем введите полученный отдельно код в адресную строку и нажмите Enter: браузер расшифрует профиль, сохранит его в системном защищённом хранилище и подключится. Код не добавляется в историю и не отправляется поисковику. После успешной настройки повторять ввод при каждом запуске не нужно.

После однократного импорта файла код также можно передать при запуске приложения аргументом:

```sh
# Mac, замените YOUR_CODE на свой код
"/Applications/Chrome Proxy Edition.app/Contents/MacOS/Chrome Proxy Edition" YOUR_CODE
```

В Windows передайте код после пути к `Chrome Proxy Edition.exe`. Приложение должно быть установлено; команда не является системной командой терминала сама по себе.

Шифрование файла профиля не превращает распространяемый пароль в неизвлекаемый секрет. Любой, кто знает код и получил программу, может восстановить профиль. Это удобный импорт настроек, а не средство контроля доступа к серверу. Для публичного распространения используйте отдельные пользовательские пароли.

## Сеть и данные

- Вкладки, адресная строка, поиск Google, закладки, загрузки, последние 200 записей истории сохранены.
- Перед включением и каждые 30 секунд клиент проверяется через прокси запросом к `https://example.com/`. Недоступность этой страницы приводит к блокировке, даже если другие сайты доступны.
- При ошибке/обрыве клиент не переключается на прямой интернет. Для прямого подключения нужна явная кнопка «Выключить VPN» и подтверждение.
- При переключениях сетевые соединения и страницы закрываются, загрузки отменяются. Адреса вкладок остаются, но несохранённый ввод теряется.
- WebRTC ограничен `disable_non_proxied_udp`, QUIC отключён. Разрешения камеры, микрофона, уведомлений и геолокации пока отклоняются. Независимый аудит DNS/WebRTC-утечек не проводился.
- Трафик вкладок идёт по AnyTLS; системный DNS может использоваться для первоначального разрешения имени самого сервера AnyTLS.
- Для сохранения истории, cookies и закладок используется прежний каталог профиля `Mieru Browser`. Настройки AnyTLS хранятся отдельно от старых настроек Mieru; старые учётные данные не переносятся в новый протокол.
- На время работы sing-box расшифрованная конфигурация находится в приватном runtime-файле. На Unix каталог 0700, файл 0600; на Windows — ACL пользовательского профиля. Файл удаляется при остановке и следующем запуске после аварии. Процессы с правами того же пользователя могут прочитать его.
- Нет Chrome Sync, поддержки магазина Chrome Extensions, DRM/Widevine и автоматического обновления. Это экспериментальный браузер, а не сборка Google Chrome.

## Разработка и сборка

Node.js 24, Python 3 и git:

```sh
npm ci
python3 scripts/fetch-sing-box.py
npm test
npm start
```

На Windows используйте `python` вместо `python3`. Скрипт загрузки использует официальный релиз, закреплённую версию и SHA-256; извлекается только исполняемый файл. Версии npm закреплены в package-lock.json.

```sh
# На Mac Apple Silicon
python3 scripts/fetch-sing-box.py --os mac --arch arm64
npm run dist -- --mac --arm64
node scripts/verify-mac.cjs arm64

# На Mac Intel
python3 scripts/fetch-sing-box.py --os mac --arch x64
npm run dist -- --mac --x64
node scripts/verify-mac.cjs x64

# На Windows
python scripts/fetch-sing-box.py --os win --arch x64
npm run dist -- --win --x64
```

GitHub Actions собирает все три установщика, проверяет встроенный клиент и публикует новый prerelease при изменении версии. Существующие релизы не перезаписываются.

## Проверки

`npm test` проверяет импорт JSON/URL, TLS-политику, маршрутизацию без обхода, расшифровку профиля, блокировку при сбоях, запуск sing-box и очистку временных настроек. При наличии бинарника интеграционный тест поднимает локальный AnyTLS-сервер с тестовым сертификатом, проводит HTTP через TLS и проверяет отказ с неверным паролем и недоверенным сертификатом. Ключи в `test/fixtures` предназначены исключительно для локального тестового сервера, их нельзя использовать на реальном сервере.

`npm run smoke` проверяет окно Electron, первый запуск, IPC, вкладки и блокировку до подключения. В ограниченном Linux-контейнере можно выполнить `SKIP_NETWORK_TESTS=1 npm test` (пропустит только живые сетевые тесты) и `npm run smoke -- --no-sandbox --ozone-platform=headless --disable-gpu`. `--no-sandbox` используется только для теста от root; обычное приложение запускается с sandbox.

Без данных и доступа к реальному серверу нельзя гарантировать подключение из конкретной сети, в частности при блокировке IP или домена.
