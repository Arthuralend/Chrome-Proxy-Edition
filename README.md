# Mieru Browser / Chrome Proxy Edition

Экспериментальный браузер на **Chromium (Electron)** для **macOS Intel, macOS Apple Silicon и Windows x64**. Это самостоятельное приложение, не Google Chrome. Кнопка VPN управляет прокси Mieru только внутри этого браузера.

## Возможности версии 0.1

- Вкладки, адресная строка с поиском, назад/вперёд, загрузки, закладки и последние 200 адресов истории.
- Первоначальная настройка: вставьте **полный клиентский JSON Mieru**, затем нажмите «Сохранить и подключиться».
- Встроенный клиент Mieru 3.38.1; отдельная установка не нужна.
- Автоподключение при запуске включено по умолчанию; его можно отключить при сохранении конфигурации.
- Настройки хранятся через Electron safeStorage: системное шифрование Keychain на macOS / DPAPI на Windows. Они не записываются в репозиторий.
- При старте, подключении и ошибке сеть страниц блокируется. Прямое соединение включается только кнопкой «Выключить VPN» с подтверждением.
- Соединение проверяется через Mieru запросом к `https://example.com/` перед включением и каждые 30 секунд. Если этот сайт недоступен, подключение считается неподтверждённым, даже если другие сайты работают.

При переключении подключения открытые веб-страницы пересоздаются, активные загрузки отменяются, несохранённый ввод в страницах теряется. Адреса вкладок остаются; активная страница загружается заново. Это закрывает прежние сетевые соединения, включая WebSocket.

## Установка готовой сборки

В GitHub откройте **Actions → Build desktop apps → успешный запуск → Artifacts**:

| Система | Артефакт | Установка |
|---|---|---|
| Windows 10/11 x64 | Mieru-Browser-win-x64 | Откройте `.exe` |
| Mac Intel | Mieru-Browser-mac-x64 | Откройте `.dmg`, перенесите приложение в Applications |
| Mac M1/M2/M3/M4 и другие Apple Silicon | Mieru-Browser-mac-arm64 | Откройте `.dmg`, перенесите приложение в Applications |

Первые сборки не подписаны сертификатами Apple/Microsoft. ОС может показать предупреждение об неизвестном разработчике. Для публичной стабильной поставки нужны подпись и notarization на Mac и подпись Windows. Автообновлений пока нет.

При теге `v*` workflow создаёт предварительный релиз с установщиками. Без тега сборки доступны в Artifacts. В репозиторий не нужно загружать двоичные файлы клиента или `node_modules`.

## Настройки подключения

Пример ниже **не подключается к рабочему серверу**. Замените адрес, порт, протокол, имя и пароль на данные своего сервера **mita**. Если ваша конфигурация содержит MTU, multiplexing, handshakeMode, trafficPattern или несколько серверов, вставьте её целиком, сохранив эти поля.

```json
{
  "profiles": [{
    "profileName": "default",
    "user": { "name": "YOUR_USERNAME", "password": "YOUR_PASSWORD" },
    "servers": [{
      "domainName": "YOUR_SERVER.example",
      "portBindings": [{ "port": 443, "protocol": "TCP" }]
    }]
  }],
  "activeProfile": "default"
}
```

Для IP-адреса замените `domainName` на `ipAddress`. Поддерживается `portRange`, например `"2000-2010"`. Ссылки `mieru://` и `mierus://` в этой версии не импортируются: сначала экспортируйте JSON. Браузер сам назначает свободные локальные SOCKS/RPC-порты, запрещает доступ из LAN, отключает локальный HTTP-прокси и локальную SOCKS-аутентификацию. Серверные учётные данные сохраняются.

Окно изменения настроек намеренно не показывает сохранённый пароль: чтобы заменить настройки, вставьте конфигурацию заново. При неуспешной проверке исправленный JSON остаётся в поле до повторной попытки; при успешной проверке поле очищается.

## Разработка

Нужны Node.js 24, npm, Python 3 и git. macOS-сборки создаются на macOS; Windows-сборки — на Windows. На Windows вместо `python3` используйте `python`.

```sh
git clone https://github.com/Arthuralend/Chrome-Proxy-Edition.git
cd Chrome-Proxy-Edition
npm ci
python3 scripts/fetch-mieru.py
npm test
npm start
```

Для сборки на своей системе:

```sh
# Mac Apple Silicon
python3 scripts/fetch-mieru.py --os mac --arch arm64
npm run dist -- --mac --arm64

# Mac Intel
python3 scripts/fetch-mieru.py --os mac --arch x64
npm run dist -- --mac --x64

# Windows x64 (PowerShell)
python scripts/fetch-mieru.py --os win --arch x64
npm run dist -- --win --x64
```

Скрипт загружает Mieru из официального релиза, сверяет SHA-256 с закреплённым в коде и извлекает только исполняемый файл. Версии Electron и сборщика закреплены в package-lock.json.

## Границы защиты и ограничения

- Веб-сайты изолированы от Node.js и управляющего IPC; используются sandbox и context isolation. Приложение не игнорирует ошибки TLS.
- WebRTC ограничен политикой `disable_non_proxied_udp`, QUIC отключён, обход прокси для loopback отключён. Разрешения камеры, микрофона, геолокации и уведомлений пока отклоняются.
- Это прототип, не прошедший независимый аудит утечек DNS/WebRTC и длительную проверку на обеих ОС. Не следует считать его готовым решением для анонимности.
- Из-за CLI Mieru расшифрованная конфигурация существует на диске **на время работы клиента** в приватном каталоге приложения; удаляется при остановке и следующем старте после аварии. macOS: каталог 0700, файл 0600; на Windows защита зависит от ACL пользовательского профиля. Системное шифрование защищает сохранённую копию, но не от программ, работающих с правами того же пользователя.
- История, cookies и закладки сохраняются локально без дополнительного шифрования, приватного режима пока нет.
- Нет Chrome Sync, магазина расширений, поддержки DRM/Widevine или гарантии совместимости Google-входа; Electron не является полноценной заменой Google Chrome.
- Запрос проверки `example.com` выполняется только через Mieru. Сторонней аналитики нет. Поиск по умолчанию отправляется Google.

## Проверка перед релизом

`npm test` проверяет валидацию JSON, запрет служебных URL, закрытие сетевого шлюза при ошибках и порядок переключения режимов. На каждой целевой ОС дополнительно нужны запуск установщика, вставка реальной конфигурации, сравнение внешнего IP, проверка DNS/WebRTC, остановка сервера во время загрузки и WebSocket, перезапуск приложения, скачивание файла, проверка очистки runtime-конфигурации. Без реального сервера проверку сквозного соединения завершить нельзя.

`npm run smoke` проверяет реальное окно Electron: первый запуск, IPC, вкладки, состояние интерфейса и блокировку навигации до подключения. Тест использует отдельный временный профиль без пользовательских данных. В Linux-контейнере без дисплея: `npm run smoke -- --no-sandbox --ozone-platform=headless --disable-gpu`. Флаг `--no-sandbox` нужен только для этого контейнерного теста от root; обычное приложение работает с sandbox.
