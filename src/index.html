Подключите свой AnyTLS

Введите данные своего сервера AnyTLS. Они сохраняются на этом устройстве. Клиент встроен в браузер.

Проверка сертификата включена по умолчанию. Отключайте её только осознанно для своего сервера с самоподписанным сертификатом. При доступе по IP в SNI укажите домен из сертификата.

Импорт JSON или ссылки anytls://

Если это поле заполнено, используются данные из него. Поддерживаются простой JSON, один outbound AnyTLS из sing-box и anytls://пароль@сервер:порт?sni=домен. Старый JSON Mieru не подходит.

При включённой защите браузер не переключается на прямое соединение. Пока подключение не подтверждено, страницы заблокированы.
